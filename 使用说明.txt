校园网一键连接 · Windows 10 / 11（64 位）

首次使用
1. 双击 CampusConnect.exe。
2. 填写校园 Wi-Fi 名称（SSID）。首次使用，请先在 Windows 中手动连接该 Wi-Fi 一次并保存网络；Wi-Fi 自身的密码由 Windows 管理。
   在系统设置里“忘记”该网络会连保存的 Wi-Fi 密码一起删掉，此后本工具无法再自动连接（会提示“Windows 里没有保存名为…”）。重新在系统里连一次该 Wi-Fi 即可恢复，无需改动本工具的任何设置。
   SSID 留空时，使用电脑当前的网络，也可用于有线校园网。
3. 认证地址：把预填的示例地址改成你学校的实际认证地址，格式形如 http://<认证服务器>/srun_portal_pc?ac_id=1&theme=pro
4. 填写校园网账号和校园网登录密码，点击“连接网络”。
5. 点击左侧栏底部“桌面图标”创建快捷方式。以后开机后双击桌面“校园网一键连接”即可自动连接。

日常使用
默认勾选“下次打开程序时自动连接”。它表示双击图标即连接。
勾选“开机时自动启动本工具”后，登录 Windows 时会自动打开本工具；若同时勾选了上面的自动连接，就会在开机后自动联网。该选项默认关闭，勾选即生效，取消勾选会立即移除启动项。程序只写入当前用户的启动项（注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 CampusConnect），不需要管理员权限，也不会添加后台服务或计划任务。
开机启动时会先等待约 12 秒再连接，给无线网卡和校园 Wi-Fi 留出就绪时间。
之后程序会一直重试直到联网：失败后按 5、10、20、40、60 秒退避，之后固定每 60 秒一轮，状态栏显示“等待重试”和已持续时长，随时可点“取消连接”中止。
两种情况下会立刻停止重试：认证页明确报错（密码错误、账号停机、欠费、请求过于频繁等），或页面需要验证码、运营商选择等人工操作——后者会把认证页面留给你处理。
另外重试最多持续 30 分钟，超时后提示手动重试，避免不在校园网时（比如在家开机）一直空转。
手动点击“连接网络”只尝试一次，失败原因会立即显示。
取消勾选后，打开程序只显示设置。也可用 CampusConnect.exe --settings 直接进入设置。
已可上网时不会重复提交认证；程序窗口可以在连接成功后关闭。
修改配置后点击“保存配置”，或点击“连接网络”保存并立即连接。
取消连接只会停止后续操作，不会断开已连接的 Wi-Fi，也不会撤回已经提交的登录请求。

认证页面
程序使用微软 WebView2 加载真实认证页面，自动识别账号、密码与登录按钮，适配深澜 SRun 常见页面。
“认证页面”标签里是真正的浏览器页面，不是占位图。连接过程中一旦认证页加载完成，界面会自动切到这个标签，可以直接看到自动填写与提交的过程；联网成功后自动切回“运行记录”。其余时间点一下标签即可查看当前页面。
出现验证码、运营商选择、额外服务协议或自动识别失败时，程序会停在这个页面等你操作，不会自动刷新冲掉你已填的内容。
自动填写只在设置的同一来源（协议、主机、端口均相同）内执行；若页面跳转到其他地址，请确认学校实际认证地址后更新设置。
输入框特殊的学校，可点击左侧栏“设置”打开高级设置，填写账号、密码、登录按钮的 CSS 选择器。
Windows 保存的 Wi-Fi 配置名称与 SSID 不同，同样在左侧栏“设置”里指定配置名称。

联网状态
程序用微软联网检测页面及 Google HTTPS 204 页面检查网络。
两者都不可访问时，即使学校认证页显示已在线，也会提示“尚未确认联网”，可自行打开网页检查。
认证服务只在校园网内可访问。真实账号登录及所在学校页面的最终兼容性，需要在校园网络中验证。

数据与依赖
账号与配置：%LOCALAPPDATA%\CampusConnect\settings.json
密码使用 Windows DPAPI 当前用户加密，不会写入日志；加密文件无法直接迁移给其他 Windows 用户。
浏览器禁用自动保存密码，使用 InPrivate 会话；关闭程序后不保留认证会话 Cookie。
删除上述 settings.json 即可清除保存的账号密码（先关闭程序）。
运行要求：Windows 10/11 64 位、.NET Framework 4.7.2 或更新、WebView2 Evergreen Runtime。
若缺少 WebView2，请从微软安装：https://developer.microsoft.com/microsoft-edge/webview2/#download-section
无需安装 Python、Node.js，不需要管理员权限。桌面快捷方式指向本目录，移动文件夹后需重新创建快捷方式。
请保留 CampusConnect.exe、三个 DLL 和 campus.ico 在同一文件夹。

安装与卸载
使用安装包安装时，程序位于 %LOCALAPPDATA%\Programs\CampusConnect，全程不需要管理员权限。
卸载请在「设置 → 应用」中找到「校园网一键连接」，或运行安装目录下的 uninstall.exe。
卸载会一并清除开始菜单与桌面快捷方式、开机自启项和浏览器缓存，并询问是否删除已保存的账号；选择保留后重新安装即可继续使用，无需重新填写。
账号与配置始终保存在 %LOCALAPPDATA%\CampusConnect，与程序目录分开，因此重装或更换安装位置都不会丢失。
